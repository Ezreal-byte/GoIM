# Desktop worker contract

Both workers use internal/domain/types.go and may inspect Viva source in ../viva. Do not modify domain or core.

Worker desktop-shell owns internal/desktop/app.go, chat.go, groups.go, icons.go, app_test.go. Expose `func New(backend domain.Backend) *UI`, `func (u *UI) Config() app.Config`, `func (u *UI) Close()`. UI is refreshed on OnWake from Backend.Snapshot, watches Backend.Updates to invalidate. It calls Panels below for modules settings/transfers/shares. Do not import core or write main. UI provides stable ID names via ui.Tree. Use production empty state, no fake peers. Initial main window 1440x960, minimum sensible 1000x700. Use selected reference styles. TextInput provider must combine shell fields and Panels.TextInput. User-authorized final native launch is root's job; workers use Driver/headless only.

Worker desktop-panels owns internal/desktop/panels.go, settings.go, transfers.go, panels_test.go. Implement independent exported `type Panels struct`, `func (p *Panels) Draw(canvas *ui.Canvas, theme ui.Theme, bounds ui.Rect, module string, state domain.State, submit func(domain.Command))`, `func (p *Panels) TextInput() app.TextInputProvider`. Module strings settings, transfers, shares. It owns its tree, flex.View and fields; may use a distinct tree? MUST use shell's ui.Tree to avoid ID collisions: implement `func (p *Panels) Init(tree *ui.Tree)` called once by shell. Draw renders ONLY within bounds excluding outer 68px rail. Settings draws 300px category column and remaining options; other panels may use full bounds. Shell calls it and combines native field providers. No global repaint timer. Do not implement core or shell. Panels controls must submit actual domain commands.

Commands: Connect.Address; StartChat.PeerID; SendText.ConversationID/Text; SendFiles.ConversationID/Paths; CreateGroup.Name/IDs; InviteMembers.GroupID/IDs; AcceptInvite/RejectInvite.InvitationID; RenameGroup.GroupID/Name; RemoveMember/TransferOwner.GroupID/PeerID; LeaveGroup/DissolveGroup.GroupID; AcceptTransfer.TransferID and optional Paths[0] destination; Reject/Cancel/Retry.TransferID; ShareFiles.Paths; GetShared.FileID; RemoveShare.FileID; RefreshShares; SetContactGroup.PeerID/Name; TogglePin/ToggleMute/MarkRead.ConversationID; SaveDraft.ConversationID/Text; SetProfile.Name/Value(avatar path); SetSetting.Setting/Value/Bool.

Setting keys: theme (light/dark), desktop_notifications (Bool), sound (Bool), download_dir (Value), duplicate_policy (rename/ask), auto_accept (Bool), network (Value interface name or auto), close_to_tray (Bool), send_key (Enter/Ctrl+Enter), shortcuts (Value JSON []domain.Shortcut), reset_shortcuts. All core updates surface via snapshots. Errors state.Error, feedback state.Notice. Version state.Version. Files.SourcePath is local only; received paths in completed Transfers.Path. External avatars/images decode/cache off Paint; using initials fallback is fine.

File controls use Viva app.OpenFiles/OpenDirectory/SaveFile and app.OpenPath/RevealPath APIs (read signatures before using). Native dialogue cancellation is not an error. No custom OS calls in app for reusable desktop capabilities. Ordinary UI fields use flex.Field. Command outcomes are asynchronous; mark progress and refresh from backend. UI-only drafts/navigation selection may remain local.
