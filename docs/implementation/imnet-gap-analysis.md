# GoIM 与内网通：下一阶段候选

对照本机安装的内网通 3.4 随附帮助（`Nwt/Help/Help.htm`）、[内网通产品介绍](https://www.51nwt.com/products.htm)和[官方更新日志](https://51nwt.com/rizhi.htm)。下表按 GoIM 四个现有模块归类。官方资料和本机帮助能确认产品能力；没有把某个版本的实测互通作为结论。

| 区域 | GoIM 现状 | 可补的能力 |
| --- | --- | --- |
| 消息 | 单聊、确认入群、`@`、本地记录、当前会话搜索、发件人在线时补发 | 多人群发（独立单聊，不建群）、撤回、可选已读回执、群公告、跨会话搜索和聊天记录导出 |
| 联系人 | 自动发现、手动 IP 连接、本地分组、昵称／签名／在线状态 | 多网段地址范围、组织目录导入、屏蔽与信任名单、按联系人设置上线提醒 |
| 传输 | 文件逐人确认、取消重试、断点续传；GoIM 协议可对照发送方 SHA-256 | 整个文件夹传输、资源管理器右键发送、多选批量操作；旧客户端扩展协议需逐版本实测 |
| 文件 | 选定文件的只读分享，浏览器下载、密码和二维码 | 一个链接分享多文件、可选有效期、目录分享；不建议默认递归公开整个目录 |
| 设置与交互 | 两种主题、聊天背景、应用锁、快捷键、声音／桌面通知、经典表情、截图标注 | 单会话免打扰、消息预览控制、可导入表情包、可选更多皮肤、可配置的自动锁定与可恢复备份 |
| 超出当前范围 | 无中心服务器，四个本地模块 | 内网通远程协助和邮件提醒涉及额外权限或外部服务，适合另行立项 |

建议先做**互通验收、文件夹发送和单会话免打扰**，再做记录搜索导出、群公告、跨网段发现。撤回只能请求已连接的 GoIM 端删除消息；文件已保存或消息已复制时不能收回副本。已读回执应可关闭。

互通验收按方向记录：GoIM ↔ 内网通 3.4、GoIM ↔ 飞鸽指定版本、GoIM ↔ 飞秋指定版本。每一对都验证双向发现、中文文本、普通文件确认下载、中文文件名和中断重试，记录版本、端口及文件哈希。当前基础 IPMSG 使用 UDP/TCP 2425，旧版链路没有 GoIM 的 TLS 身份认证；需要独立主机或隔离网络环境避免同机端口争用。[IP Messenger 官方端口说明](https://ipmsg.org/help/ipmsghlp_eng.htm)、[飞鸽官方互通说明](https://www.ipmsg.org.cn/index/help.html)。
