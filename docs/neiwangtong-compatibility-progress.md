# 内网通适配进度

验收基线：GoIM 0.1.2，Viva `93ab37d73f53`，原版内网通 `3.4.3055`。更新于 2026-11-17。状态按场景记录；“原版通过”仅指该行列出的范围。

| 功能 | 进度 | 现有证据与待补验收 |
| --- | --- | --- |
| 指定地址发现、资料握手 | 原版通过 | 沙箱和 VMware 原版均建立控制连接；已有重复握手导致断线的回归用例。 |
| 局域网广播发现、联系人列表 | 原版初验通过 | 本机开发客户端用空白档案启动，未手填地址即发现 VMware 网段内在线的原版联系人。多网卡选择、对端上下线和列表刷新仍待专项验收。 |
| 自动选择协议 | 路由回归、原版发现初验通过 | GoIM 对端用 GoIM 协议，内网通走原生连接，飞鸽／飞秋走 IPMSG。联网预览发现原版时只保留一个在线的内网通联系人；已经确认过的旧关联保留聊天身份，新的发送等待原生连接。 |
| 在线状态变化 | 仅回环或单元验证 | 已有原版状态值的映射测试；待核对原版切换忙碌、离开及退出时的显示。 |
| 单聊文字 | 原版通过 | 沙箱验证双向中文文字，包含特殊字符。 |
| 应用回执 | 原版通过 | GoIM 发给原版后，按对端和消息 ID 匹配应用回执；它不等同于已读。 |
| GoIM 获取原版头像 | 原版通过 | VMware 原版返回有效 PNG，已核对尺寸和 SHA-256。 |
| 头像更新和清除 | 仅回环验证 | 待验证原版更新后 GoIM 是否刷新，以及原版是否显示 GoIM 的更新。 |
| 在线普通文件 | 原版通过 | 沙箱验证双向收发、中文文件名和落盘 SHA-256；每个方向用 98,321 字节的样本。 |
| 文件拒收 | 原版通过 | 原版拒收后 GoIM 报告已拒收；GoIM 拒收后原版可以重发同一个文件，重发的文件通过 SHA-256 校验。 |
| 文件撤回、取消 | 原版通过（已列场景） | 双方作为发送方都能撤回待接收的文件。原版在收文件中途取消时，GoIM 显示已取消并停止发送；原版可能保留已收的部分，沙箱确认没有完整成品。 |
| 普通文件断点续传 | 原版双向通过 | 原版发送时，GoIM 从保留的 32,768 字节继续，最终 SHA-256 一致。原版接收时，实际落盘 32,768 字节后让 GoIM 服务断开并重启；原版请求同一偏移，收到完整 512 KiB，SHA-256 一致。另有 GoIM 接收端真实 TCP 中断回归。 |
| 4 GiB 及以上单文件 | 原版→GoIM 通过 | 单文件 4,295,032,849 字节实际落盘并通过 SHA-256 校验。GoIM→原版的分块发送在延长到 4 分钟的专项中仍未完成，因此 GoIM 界面发给原版的单文件仍须小于 4 GiB。 |
| 文件夹单聊直传 | 原版双向通过 | 顶层文件、多层中文路径、空子目录和 0 字节文件均保留；逐文件 SHA-256 一致。GoIM 接收完成后才发布目录，不覆盖同名目录。完全空的根目录暂不发送，目录断点续传未实现。 |
| 单聊内联图片 | PNG、JPEG、GIF 原版双向通过 | GoIM 收到的三个格式与样本逐字节一致，GIF 样本有两帧；三个反向样本均从原版实际写出的缓存核对 SHA-256。 |
| 离线单聊文字和文件 | 原版双向通过 | 两个方向都让接收端实际下线。原版发出的补投文字在 GoIM 中保留原发送时间，文件通过 SHA-256。GoIM 在原版关闭时排队并重启自身；原版重新上线后，会话中出现原文，收到的文件通过 SHA-256。补投依赖两端再次同时在线。 |
| 原版创建的群聊 | 群文字原版双向通过 | 原版创建测试群，GoIM 收到成员和完整群文字；脚本从原版群会话里读出了 GoIM 的回复正文。GoIM 创建或管理原版群、群文件和群图片未适配。 |
| 原版表情与消息撤回 | 未适配 | 独立于聊天图片；待捕获并验证原版行为。 |
| 原版文件共享、远程协助 | 未适配 | 独立于普通文件发送，单独评估范围。 |

| 建议顺序 | 工作 | 验收条件 |
| --- | --- | --- |
| 1 | 补齐局域网发现专项，同时核对联系人 UI | 在有多块网卡的情况下，确认选中的网段能发现原版；原版上线、退出和重连时列表能正确刷新。 |
| 2 | 补齐目录续传 | 在隔离网络中断目录传输，核对原版清单里每个文件的已收偏移和最终 SHA-256。 |
| 3 | 扩展原版群聊 | 多成员收发和成员变更分开验收，再处理 GoIM 建群、群附件和群管理。 |
| 4 | 扩展文件和聊天内容 | 继续验证 GoIM 向原版发送 4 GiB 以上文件，补表情和撤回。 |

集中联调时，用户侧只需准备一台实际使用的 Windows 内网通，记下版本号，并和 GoIM 测试机连到同一办公网段。一起核对双方无需手输 IP 就能互相发现，以及消息和文件的基本操作；如果有第三位测试成员，再一起核对真实多人群。协议偏移、哈希、原版缓存和沙箱内的群文字无需人工核对。

复跑命令、环境要求和报告格式见[内网通互通验证](neiwangtong-testing.md)。未适配项参考[原版更新日志](https://www.51nwt.com/rizhi.htm)和[原版文件传输说明](https://51nwt.com/help/g5.htm)。
