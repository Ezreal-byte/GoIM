# GoIM 0.2.0

## 在线更新

- Linux DEB 安装版新增应用内更新。下载支持断点续传，并校验发布签名、包的版本、架构和 SHA-256。系统授权和软件包复核通过后，GoIM 才会退出，安装完成后以原用户重启。
- 从 0.1.23 等早期 DEB 版本升级时，请先手动安装 0.2.0 的 DEB。此后可在「设置 → 关于」更新到后续稳定版。缺少桌面授权服务时可手动安装官方 DEB。
- macOS 在线更新支持位于可写外置盘的 GoIM 应用。发布构建会复核 Intel 和 Apple 芯片版 ZIP 的应用标识、版本及签名。

## Windows 托盘

- 鼠标悬停托盘图标即可查看紧凑的未读会话浮层。浮层显示头像、未读数和群聊最近发言人，点击会话可直接打开聊天。
- 点击「暂不处理」会收起浮层、结束本轮提示并保留未读。下一条需要提醒的新消息到来时，托盘闪动和悬停提醒会恢复。

## 安装包

| 平台 | 架构 | 安装包 |
| --- | --- | --- |
| Windows | x64、ARM64 | Setup 安装程序（.exe）、便携版 .zip |
| macOS | Intel、Apple 芯片 | .dmg、.zip |
| Linux | amd64、arm64 | .deb、.tar.gz |

可使用随附的 `SHA256SUMS` 校验安装包。Linux 的 `file-dialog-sources.tar.xz` 是文件选择器依赖源码。
