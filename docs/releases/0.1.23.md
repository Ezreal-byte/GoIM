# GoIM 0.1.23

## 修复与改进

- 来电浮窗首次显示在屏幕可用区域的右下角，支持拖动并记住位置。修复 Windows 高缩放下浮窗越界的问题。Wayland 系统通知的位置由桌面管理，通知发送失败时会显示 GoIM 的备用浮窗。
- 主窗口关闭到托盘后仍会收到新消息提醒并触发托盘闪烁。未读菜单可直接打开会话，并显示群聊最近发言人。锁定应用或隐藏通知内容时，菜单会隐藏发件人。
- 表情面板采用 Fluent Emoji 3D。Linux 缺少系统彩色表情字体时，输入框和聊天气泡也能显示面板内的彩色表情。
- Windows 11 主窗口外框跟随当前主题，修复切换深色主题后窗口四周仍有白边的问题。

## 安装

已安装 `0.2.22` 的用户请手动下载 `0.1.23`。应用内更新器按版本号比较，不会将 `0.1.23` 识别为更新。

| 平台 | 架构 | 安装包 |
| --- | --- | --- |
| Windows | x64、ARM64 | Setup 安装程序（.exe）、便携版 .zip |
| macOS | Intel、Apple 芯片 | .dmg、.zip |
| Linux | amd64、arm64 | .deb、.tar.gz |

安装包可使用随附的 `SHA256SUMS` 校验。Linux 的 `file-dialog-sources.tar.xz` 是文件选择器依赖源码。
