# GoIM 0.1.9

## 新功能

- 应用锁新增系统凭据解锁。GoIM 锁定时可以选择使用系统验证，支持 Windows Hello 的 PIN、指纹或人脸、macOS Touch ID 或登录密码，以及 Linux 桌面 polkit 认证。
- 系统验证只负责本次解锁，取消或失败后 GoIM 仍保持锁定，原有 GoIM 锁定密码继续作为兜底方式。

## 改进

- 左侧栏切换外观后不再弹出“已保存”提示，主题仍会立即应用并自动持久化。
- 移除设置左栏底部的“设置自动保存在本机”，只保留右下角的“修改后自动保存”说明。
- 统一文件传输与文件共享页面的 TAB 字号，两个页面的筛选栏现在使用相同的 16 px 字体。
- 完善 PR CI：新增格式与 vet、单元与集成测试、Race、Windows 桌面测试和 Hello 原生探针、三进程冒烟等独立任务。
- 文档、网站和 issue 模板的纯文档改动会跳过 Go 测试套件；同一 PR 的新提交会取消旧任务，减少排队时间。
- GitHub Actions 工作流统一命名为 `tests.yml`、`release.yml` 和 `website.yml`，并升级到 Node 24 版官方 Actions。

## 修复

- 修复 Windows Hello 可用性探针把错误返回值与 `DeviceNotPresent` 混用的问题，正确区分未知错误、未配置、策略禁用和设备忙状态。
- 修复系统验证不可用时原生探针可能误判互操作路径的问题。
- 修复设置页重复显示自动保存说明，以及文件共享筛选 TAB 与其他文件页面字号不一致的问题。

## 更新概览

| 类别 | 主要变更 | 结果 |
| --- | --- | --- |
| 安全 | 系统凭据解锁 | Windows Hello、macOS LocalAuthentication、Linux polkit；失败时保持锁定并回退 GoIM 密码 |
| 桌面体验 | 外观切换与设置页整理 | 切换主题不再显示保存提示；自动保存说明只保留右下角 |
| 界面一致性 | 文件页面筛选栏 | 文件传输与文件共享使用统一字号和视觉节奏 |
| 持续集成 | PR 与 Windows 质量门禁 | 独立质量、测试、Race、Windows 冒烟任务，覆盖 Hello 原生探针 |

## 安装

| 平台 | 架构 | 软件包 |
| --- | --- | --- |
| Windows 10 或更新版本 | x64、ARM64 | Viva `Setup.exe`、便携版 `.zip` |
| macOS 13 或更新版本 | Intel、Apple 芯片 | `.dmg`、`.zip` |
| Linux（X11 或 XWayland） | x64、ARM64 | `.deb`、`.tar.gz` |

Windows 使用 Viva 安装向导，默认只给当前用户安装。压缩包需完整解压，保留 GoIM 与截图工具的相对位置。Linux 系统仍需提供 DEB 依赖中声明的 X11、XKB 和 Vulkan 运行库。
