# GoIM 0.2.6

## 新功能

- 私聊支持远程协助。点击语音通话旁的远程协助图标，对方接受后即可共享画面并操作键鼠。控制窗口提供全屏和快捷键，被协助方可随时停止共享。
- 文件共享支持下载统计。在「设置 → 文件共享」开启后，「我的分享」和文件夹详情会显示可排序的下载次数。统计关闭时暂停计数，已有记录会保留。
- 双击「我的分享」里的文件夹可进入紧凑的文件列表，支持逐级浏览、返回和刷新。点击访问方式列的链条或锁图标，可以在默认浏览器打开分享链接。
- 聊天输入框支持混合编辑文字、文件、图片和视频。发送前可以预览或移除附件，未发送内容会留在草稿中。

## 改进

- 锁定页跟随当前明暗模式与主题配色，沿用主窗口顶栏。在支持的平台上，可通过 Windows Hello 或 Touch ID 解锁。
- 再次启动 GoIM 时会唤回已经运行的窗口。历史消息快照减少了序列化开销。
- 托盘预览显示未读会话，可点击直达聊天。「暂不处理」会暂停本轮提醒，收到新消息后恢复。Windows 和 macOS 可悬停打开预览，Linux 可从托盘图标或菜单进入未读列表。锁定应用或关闭消息预览时会隐藏发件人信息。

## 修复

- 修复 Linux X11 缩放下点击托盘图标时，未读列表可能远离图标的问题。
- 修复开发模式局域网发现可能把单实例唤醒端口识别为联系人服务的问题。

## 安装

| 平台 | 架构 | 安装包 |
| --- | --- | --- |
| Windows | x64、ARM64 | Setup 安装程序（.exe）、便携版 .zip |
| macOS | Intel、Apple 芯片 | .dmg、.zip |
| Linux | amd64、arm64 | .deb、.tar.gz |

手动覆盖安装前，请先从系统托盘完全退出旧版 GoIM。可使用 `SHA256SUMS` 校验安装包。

macOS 被协助端需在系统设置中授权屏幕录制和辅助功能。Linux 的 Wayland 会话依赖桌面提供屏幕共享和远程桌面门户。
