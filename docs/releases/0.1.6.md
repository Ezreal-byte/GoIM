# GoIM 0.1.6

本次更新集中完善 Viva 桌面端的日常使用体验：

- 界面字体选择器改用原生滚动区域，支持滚轮和拖动滚动条，键盘切换字体时自动定位到选中项。
- 个人资料保存只显示一次轻提示，独立会话窗口不再重复显示主窗口通知。
- 独立会话窗口使用统一的自定义标题栏和置顶按钮；拖动会话时显示跟随鼠标的预览卡片，主窗口右侧内容区保持留空。
- 修复表情选择后编辑框重复显示的问题。
- 合并诊断与反馈入口，仅导出脱敏后的版本、协议状态、适配器和数据计数。
- 新增自动检查更新开关，默认开启；关闭后仍可手动检查。
- 更新提示改为标题栏绿色图标，更新弹窗展示 GitHub 发布说明。
- QQ 群入口改为直接打开群链接。
- 自动保存的设置页不再显示没有意义的“保存中”状态。

本版本继续提供 Windows ZIP 与 Viva NSIS Setup、macOS ZIP 与 DMG、Linux tar.gz 与 DEB，共六个平台架构、十二个软件包。
