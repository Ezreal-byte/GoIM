# GoIM 0.2.5

## 新功能

- 新增 LocalSend 互通。Windows、macOS 和 Linux 上的 GoIM 可以与同一局域网内的 LocalSend 客户端互传文件和文字，也支持发送文件夹。在「设置 → 网络」开启 LocalSend 后，左侧会出现独立入口，默认关闭。
- LocalSend 接收时可按文件勾选，也可在接收页单独修改保存目录。模块设置支持配置接收 PIN，传输记录可按方向筛选并查看每次传输的文件清单。

## 改进

- Linux 优先使用桌面环境提供的 StatusNotifier 托盘，并在该托盘不可用时尝试使用 XEmbed，兼容旧版 X11 桌面环境。

## 修复

- 修复 macOS 上 GoIM 启动后长时间无响应、主窗口打不开的问题。截图编辑器也采用相同的启动修正。感谢 L 站用户提供故障日志和复现报告。

## 安装

| 平台 | 架构 | 安装包 |
| --- | --- | --- |
| Windows | x64、ARM64 | Setup 安装程序（.exe）、便携版 .zip |
| macOS | Intel、Apple 芯片 | .dmg、.zip |
| Linux | amd64、arm64 | .deb、.tar.gz |

已安装 GoIM 0.2.0 或更新版本的 DEB 用户可从「设置 → 关于」在线更新。手动覆盖安装前，请先从系统托盘完全退出旧版 GoIM。可使用随附的 `SHA256SUMS` 校验安装包。
