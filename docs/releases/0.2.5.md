# GoIM 0.2.5

## 改进

- Linux 优先使用桌面环境提供的状态通知托盘。桌面环境没有可用的状态通知托盘时，GoIM 回退到 XEmbed，以兼容旧版系统托盘。

## 修复

- 修复 macOS 上 GoIM 启动后长时间无响应、主窗口无法打开的问题。数据库和网络初始化前会保留进程主线程，确保 AppKit 正常启动。感谢 L 站用户提供故障日志和复现报告。

## 安装

| 平台 | 架构 | 安装包 |
| --- | --- | --- |
| Windows | x64、ARM64 | Setup 安装程序（.exe）、便携版 .zip |
| macOS | Intel、Apple 芯片 | .dmg、.zip |
| Linux | amd64、arm64 | .deb、.tar.gz |

已安装 GoIM 0.2.0 或更新版本的 DEB 用户可从「设置 → 关于」在线更新。手动覆盖安装前，请先完全退出旧版 GoIM。可使用随附的 `SHA256SUMS` 校验安装包。
