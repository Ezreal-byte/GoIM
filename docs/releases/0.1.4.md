# GoIM 0.1.4

- 重新设计「关于」页的交流与项目卡片，图标取自 Motty 当前品牌矢量资源；QQ、微信和 GitHub 分别保留彩色企鹅、绿色微信和深色 GitHub 标志。
- 复制结果和临时操作反馈改用 Viva 轻提示，不再在页面顶部持续堆叠提示。
- 手动连接弹窗补齐连接方式与地址层级，支持「自动 / GoIM / 内网通 / 飞鸽／飞秋」选择并修正字段间距。
- 局域网在线状态移到标题栏右上角；地址在悬浮提示中显示，联系人底部不再重复占位。
- 截图编辑器新增椭圆、文字和马赛克标注，支持撤销、重做、另存为和复制截图，并完善窄窗口中的工具栏布局。
- 设置页改用自动保存状态；修正常规图标与快捷键占用提示，修改密码改为独立弹窗。
- Windows 安装包改用 Viva NSIS Setup，快捷方式使用 GoIM 图标；云端 CI 不再构建 MSI。
- 修复离线联系人收到图片选择结果后闪退、自定义聊天背景重复打开选择器或恢复默认时闪退，以及聊天输入区多层边框问题。
- 增加在线检查更新、下载、安装并重启的完整流程，并在标题栏和「设置 → 关于」提供更新入口。

Windows x64 / ARM64 提供 Setup 和 ZIP；macOS Intel / Apple 芯片提供 DMG 和 ZIP；Linux x64 / ARM64 提供 DEB 和 tar.gz。发布附带 `SHA256SUMS`。Windows 安装包未使用商业签名，macOS 使用 ad-hoc 签名且未经公证。
