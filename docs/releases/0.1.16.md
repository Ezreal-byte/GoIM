# GoIM 0.1.16

## 新功能

- 新增联系人备注：在联系人或单聊的右键菜单中设置、修改或清空备注。备注优先显示，原用户名以较弱样式显示在后面，两者均可搜索。备注只保存在本机，不会修改对方资料或同步给其他人；重启、资料更新和已确认的兼容身份合并后仍保留。
- 新增独立聊天记录窗口：从聊天页或独立会话窗口打开，按关键词、日期、成员和记录类型筛选，支持搜索命中高亮及定位回聊天上下文，保留当前草稿。
- 语音来电增加铃声提示，遵循声音设置、选定扬声器和音量；接听、拒绝、取消、结束或关闭应用后停止播放。

## 改进

- Linux X11 支持透明的会话拖拽预览，预览不抢焦点、不拦截鼠标。桌面缺少合成器或必要扩展时自动使用窗口内预览；GTK/Wayland 无全局定位时也保留窗口内预览。
- 调整聊天中的文件、打印和通话卡片：长文件名可分行显示，文件类型与传输状态更清晰；文件和打印详情在聊天侧边区域展示，窄窗口中可单独查看并返回聊天。
- 通话记录保留呼入/呼出方向、结束原因及通话时长，支持在聊天记录窗口筛选和查看详情。
- Linux `.deb` 和 `.tar.gz` 内置备用文件选择器及所需运行库、资源和输入法模块。缺少系统文件选择器时可直接使用内置版本，安装和选择文件均无需联网；发布附件提供对应依赖源码包。

## 修复

- 修复 Linux 下头像裁剪预览显示不完整、空白，以及拖动图片时因光标兼容问题导致的闪退。选择头像后先检查图片格式、文件大小、像素尺寸及完整性；不支持、过大、损坏或不可读时直接提示，保留原头像。
- 修复头像缩略图的后台结果抢先进入裁剪器、导致编辑器使用错误尺寸图片的问题。个人头像和群头像均使用通过校验的图片进入编辑。
- 统一内部弹窗的全窗口遮罩，覆盖左侧导航和顶部栏，阻止点击穿透。打印机分享、文件分享、密码、字体、快捷键和清空数据等弹窗均使用相同行为。
- 修复 Linux 安装包要求额外安装 `zenity` 或 `kdialog`、导致内网环境安装失败的问题；内置依赖使用私有目录和加载器，不替换系统库。

## 安装

| 平台 | 架构 | 安装包 |
| --- | --- | --- |
| Windows | amd64、arm64 | Setup 安装程序、便携版 `.zip` |
| macOS | amd64、arm64 | `.dmg`、`.zip` |
| Linux | amd64、arm64 | `.deb`、`.tar.gz` |

请用随附的 `SHA256SUMS` 校验下载，安装前从系统托盘退出所有 GoIM 实例。便携版请完整解压，保留随包附带的工具、运行库和资源目录。Linux 依赖源码附件以 `-file-dialog-sources.tar.xz` 结尾，日常运行无需下载。

支持自动安装的 Windows Setup 和 macOS 应用可在「关于」中检查更新；DEB 和便携版请下载对应安装包更新。

Linux 修复已在自动化测试和 Ubuntu/Xvfb 环境验证；统信 UOS、银河麒麟的具体桌面、输入法与多屏配置仍可能存在差异，欢迎附上诊断信息反馈。
