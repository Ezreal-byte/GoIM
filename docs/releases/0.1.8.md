# GoIM 0.1.8

## 新功能

- 内网通群文件支持断点续传。GoIM 接收时从已落盘偏移继续；原版接收端不支持非零偏移时，GoIM 自动使用同一邀请从头重试。
- 内网通群文件夹支持跨重连和重启续传。原版与 GoIM 双向验收通过，并保留多层中文路径、空子目录、零字节文件和逐文件 SHA-256。
- 飞鸽／飞秋补齐文字送达回执、重启后待发送消息补投和稳定登录标识，原版 IP Messenger `5.9.1` 的 12 项自动验收全部通过。

## 改进

- 在线更新提示框使用 Viva 原生 Markdown 渲染器，支持标题、粗体、列表、行内代码、代码块、表格和可点击链接。
- 更新提示框宽度由 `470px` 增至 `540px`，长发布说明更易阅读，内容仍保留在原生滚动区域内。
- Linux x64 和 ARM64 改用 Viva 的纯 Go 构建路径，安装包以 GLIBC 2.31 为兼容基线，适配银河麒麟和统信系统。
- Linux 发布校验会拒绝基础 libc、libpthread、libdl 之外的动态依赖，以及高于 GLIBC 2.31 的符号要求，并在 GLIBC 2.31 环境中执行包内程序。
- IPMSG 文件中断恢复兼容不支持非零偏移的客户端，原版 IP Messenger 会通过同一邀请从零重新接收。
- 新增内网通与飞鸽／飞秋自动验收脚本和进度文档，覆盖原版客户端发现、文字、状态、文件、回执和重连场景。

## 修复

- 修复 Linux 安装包和便携版在银河麒麟、统信系统提示缺少 `GLIBC_2.32`、`GLIBC_2.34`，安装后无法启动且没有明确提示的问题。
- 修复 IPMSG 文字在收到匹配的 `RECVMSG` 回执前就被标记为已发送的问题；回执现在按设备、端口和完整报文号匹配。
- 修复修改昵称或重启 GoIM 后 IPMSG 登录标识发生变化的问题。
- 修复部分 IPMSG 客户端拒绝非零文件偏移后传输直接失败的问题。
- 修复更新提示框将 GitHub Release 内容显示为原始 Markdown 文本的问题。
- 修复在线更新说明链接在 Viva 绘制阶段重复安排打开动作的问题。

## 安装

| 平台 | 架构 | 软件包 |
| --- | --- | --- |
| Windows 10 或更新版本 | x64、ARM64 | Viva `Setup.exe`、便携版 `.zip` |
| macOS 13 或更新版本 | Intel、Apple 芯片 | `.dmg`、`.zip` |
| Linux（X11 或 XWayland） | x64、ARM64 | `.deb`、`.tar.gz` |

Windows 使用 Viva 安装向导，默认只给当前用户安装。压缩包需完整解压，保留 GoIM 与截图工具的相对位置。Linux 系统仍需提供 DEB 依赖中声明的 X11、XKB 和 Vulkan 运行库。

内网通适配以原版 `3.4.3055` 实测为准。GoIM 向原版发送 4 GiB 及以上单文件、单聊文件夹续传、群主转让、自定义表情包、原生共享目录和远程协助仍未完成；具体飞秋 Windows 版本仍需实机验收。详见[内网通适配进度](../neiwangtong-compatibility-progress.md)和[飞鸽／飞秋适配进度](../ipmsg-compatibility-progress.md)。

Built against Viva `75594fb1481d` (GoIM fork pending upstream PR #348).
