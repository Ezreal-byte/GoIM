# GoIM 0.2.2

## 托盘未读消息

- Windows 和 macOS 托盘浮层在鼠标离开后自动收起。鼠标从图标移向浮层时，短暂经过中间空隙也能继续查看和点击未读会话。
- Windows 悬停打开原生托盘菜单时，当前窗口保留键盘焦点。点击菜单外可收起菜单，指针停在图标上时不会立即重弹。

## 来电提醒

- Windows 来电窗按目标显示器的缩放比例计算大小，并用同一套屏幕坐标保存和恢复位置。旧版记录的位置会在升级后重置一次，之后会记住拖动后的位置。
- Windows、macOS 和 Linux X11 在恢复来电窗位置时会约束到可用工作区。拔掉显示器后，来电窗会出现在离原位置最近的可用显示器上。

## 安装包

| 平台 | 架构 | 安装包 |
| --- | --- | --- |
| Windows | x64、ARM64 | Setup 安装程序（.exe）、便携版 .zip |
| macOS | Intel、Apple 芯片 | .dmg、.zip |
| Linux | amd64、arm64 | .deb、.tar.gz |

已安装 GoIM 0.2.0 或更新版本的 DEB 用户可从「设置 → 关于」在线更新。可使用随附的 `SHA256SUMS` 校验安装包。
