# GoIM 0.1.8 Beta 1

本预发布版用于验证银河麒麟和统信系统上的 Linux 安装与启动。

- Linux x64 和 ARM64 发布包改为静态 Go 构建，不再继承 Ubuntu 24.04 发布机的 GLIBC 2.32/2.34 要求。
- DEB 和 tar.gz 使用同一兼容二进制；DEB 继续声明 Viva 所需的 X11、XKB 与 Vulkan 运行库。
- 发布打包会拒绝任何动态链接 libc 的 Linux 二进制，并在 GLIBC 2.31 基线环境中执行安装包内的 GoIM 和截图工具。
- GoIM 已对齐最新 `origin/main`，并升级到 Viva 最新上游 `main`。
- Viva 原生窗口封装已补回可选的窗口缩放、全屏、置顶和快捷键捕获能力；在上游合并前，本预发布版固定使用 Viva 修复提交 `75594fb`。

这是用于实机验证的预发布版，不代表新的稳定版本。Windows 与 macOS 包也由同一 CI 构建，便于回归。
