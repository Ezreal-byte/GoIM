# GoIM 0.1.3

- Windows `Setup.exe` 改用 Viva 的 NSIS 安装向导，与 Motty 使用同一打包器。开始菜单快捷方式使用 GoIM 图标，安装完成时可选择创建桌面快捷方式。独立 MSI 的开始菜单图标也已修复。
- 点击「个人资料」里的圆形头像即可选择图片，拖动和缩放后确认裁剪；取消第二次裁剪会保留上一次确认的头像。预览直接取样原图，保存时使用同一裁剪区域。

过去通过独立 MSI 安装的用户，可直接用新版 MSI 升级。从 v0.1.1 或 v0.1.2 换用新版 Setup，请先卸载旧程序；卸载安装包不会删除默认用户数据目录里的资料和聊天记录。

Windows x64 / ARM64 提供 Setup、MSI 和 ZIP；macOS Intel / Apple 芯片提供 DMG 和 ZIP；Linux x64 / ARM64 提供 DEB 和 tar.gz。发布附带 `SHA256SUMS`。Windows 安装包未使用商业签名，macOS 使用 ad-hoc 签名且未经公证。
