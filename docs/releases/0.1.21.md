# GoIM 0.1.21

## 新功能

- Linux 版在「设置 → 网络」新增本机防火墙诊断。遇到联系人发现或连接问题时，可以查看当前网卡、局域网网段及 GoIM 实际使用的端口。使用 firewalld 或 UFW 时，可在预览后通过系统授权补齐规则。统信和麒麟使用系统安全中心管理策略时，页面会给出检查指引。
- 有新消息时，可以从托盘菜单看到未读会话及群聊的最近发言人，点击直接进入聊天。Windows 和 macOS 支持悬停展开菜单，Linux 可从桌面托盘打开菜单。锁定应用或开启隐藏通知内容后，菜单隐藏发件人。
- 共享打印记录新增「取消打印」。任务传输期间可以取消，进入系统队列后会反馈队列是否接受取消。系统正在提交任务时会暂时禁用按钮，已经输出的页面无法撤回。远程取消需要打印机共享端也支持此功能。
- 在传输记录中点击本机可用的图片或视频，可直接打开 GoIM 的独立预览窗口。

## 改进

- 进入成员共享文件夹后，工具栏左侧显示返回按钮和当前路径，右侧集中放置全选、下载所选、下载整个文件夹和刷新。
- 受密码保护的共享会显示文件或文件夹的名称。解锁页放大、居中显示「请输入分享密码」，打开后即可输入。分享端升级后，接收端才能取得原名。
- 联系人资料卡下方增加带文字的圆形「发消息」和「语音通话」按钮。主窗口右上角的 GitHub 图标可直达 GoIM 项目主页。
- 桌面界面的字号与行高跟随 Viva 的文字缩放接口，共享文件等页面按实际文字宽度排列控件，改善大字号下的显示。

## 修复

- 修复 Linux 在音频设备打开失败或不支持非阻塞模式时，报告错误可能引发的崩溃。
- 托盘菜单打开后，会在点击时复查会话状态，避免重新打开已读、被隐藏或已静音的会话。主窗口有确认弹窗时，点击托盘项会保留当前操作。

## 安装

| 平台 | 架构 | 安装包 |
| --- | --- | --- |
| Windows | x64、ARM64 | Setup 安装程序（.exe）、便携版 .zip |
| macOS | Intel、Apple 芯片 | .dmg、.zip |
| Linux | amd64、arm64 | .deb、.tar.gz |

每个安装包均可使用随附的 `SHA256SUMS` 校验。Linux 的 `file-dialog-sources.tar.xz` 是依赖源码，日常安装只需选择对应架构的 .deb 或 .tar.gz。
