# GoIM 0.1.18

## 新功能

- GoIM 客户端可以直接浏览成员分享的文件夹。点击「打开共享」即可进入目录、返回上一级、选择文件下载到接收目录。受密码保护的共享可以在客户端解锁。对方使用 0.1.17 时也支持浏览。
- 聊天中的视频可在独立媒体窗口播放，支持暂停、前后跳转 10 秒、全屏和另存为。小于 500 MiB 的聊天视频默认自动接收，达到 500 MiB 时需手动接收。可在文件接收设置中关闭自动接收。安装包随附离线解码器。

## 改进

- 浏览器共享页采用限宽的居中目录，缩短桌面端行高，并按文件类型显示与客户端一致的图标。手机上保留较大的点按区域。
- 拖动联系人时，头像、备注和用户名会随鼠标移动，松开即可归入目标分组。
- 点击群成员会在聊天右侧打开成员面板，可直接搜索、查看资料和管理成员。主窗口和独立聊天窗口均可使用。
- 新消息和语音来电分别采用 KDE Ocean 的消息提示音与来电铃声。来电铃声在接听、拒绝或对方挂断时停止。
- 在独立窗口内右键图片，可选择适应窗口、实际大小、逆时针旋转和保存原图。

## 修复

- 修复接收目录无法访问时，GoIM、飞秋或内网通文件传输在同名文件处理上可能持续重试的问题。
- 在群成员面板编辑群名时切换到聊天文件，未保存的修改会收到确认提示。

## 安装

| 平台 | 架构 | 安装包 |
| --- | --- | --- |
| Windows | amd64、arm64 | Setup 安装程序（.exe）、便携版 .zip |
| macOS | Intel、Apple 芯片 | .dmg、.zip |
| Linux | amd64、arm64 | .deb、.tar.gz |

视频播放和文件选择器都可离线使用。升级便携版时请解压整个压缩包，以便一并更新解码器及配套文件。
