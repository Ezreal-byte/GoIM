# GoIM 0.1.11

## 新功能

- 群主可在群聊成员面板上传、裁剪或移除群头像，头像会同步给支持该功能的群成员。

## 改进

- 聊天输入区使用无边框设计，工具栏置顶，发送按钮位于右下角。输入区随窗口缩放，拖动分隔线可调整高度。
- 深色外观统一为炭灰色，标题栏、导航、会话列表及聊天区使用同一底色。
- 启动时恢复上次使用的主页面。界面图标和表情面板整理了间距、状态提示和最近使用区域。

## 修复

- 修复 Windows 聊天输入框聚焦时彩色表情在下方重影的问题。表情在插入位置显示一次，移开焦点后草稿内容保持一致。

## 安装

| 平台 | 架构 | 安装包 |
| --- | --- | --- |
| Windows | amd64、arm64 | Setup 安装程序、便携版 `.zip` |
| macOS | amd64、arm64 | `.dmg`、`.zip` |
| Linux | amd64、arm64 | `.deb`、`.tar.gz` |

Windows 的当前用户 Setup 安装版和放在可写目录中的 macOS 应用可通过「设置 → 关于」检查更新。便携版和 Linux 请下载对应软件包。可用随附的 `SHA256SUMS` 校验下载。
