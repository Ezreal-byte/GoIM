# GoIM 0.2.3

## 新功能

- 支持直接 XEmbed 托盘的 Linux X11 桌面新增未读会话悬停浮层，可点击会话进入聊天。此入口需要桌面直接传递托盘鼠标事件，且系统可用 GTK3。

## 改进

- 消息通知设置改为「打开消息预览」，默认开启。升级保留原有隐私选择；关闭后，托盘仍显示匿名的「新消息」与未读数量，隐藏联系人头像、名称和群聊最近发言人。
- 有未读消息时，点击托盘图标也可打开会话列表；选择会话即可进入聊天。应用锁定时先显示解锁界面。
- 麒麟常见的 UKUI、KDE 等 SNI／代理托盘仍在悬停时显示系统文字提示，点击托盘图标或菜单后打开交互列表。本版未实现这类桌面上的自绘悬停卡片，也不将 X11 的验证结果作为原生 Wayland 的支持承诺。

## 修复

- 修复 Windows 折叠托盘返回局部坐标时，未读浮层出现在屏幕左上角或立即消失的问题。
- 修复 Linux X11 浮层的重绘事件滞留、窗口内容失效后未重新绘制的问题，避免出现空白卡片、必须移入鼠标或再次点击才显示内容的情况。
- 修复关闭消息预览后未读浮层被整体禁用的问题。已打开的浮层也会立即隐藏身份信息，保留查看未读数量和「暂不处理」操作。

## 安装

| 平台 | 架构 | 安装包 |
| --- | --- | --- |
| Windows | x64、ARM64 | Setup 安装程序（.exe）、便携版 .zip |
| macOS | Intel、Apple 芯片 | .dmg、.zip |
| Linux | amd64、arm64 | .deb、.tar.gz |

已安装 GoIM 0.2.0 或更新版本的 DEB 用户可从「设置 → 关于」在线更新。可使用随附的 `SHA256SUMS` 校验安装包。

本次 Linux 浮层修复不新增打包依赖，继续保留原有离线文件选择器。
