# GoIM 0.1.14

## 新功能

- 「设置 → 关于」新增「清除所有用户数据」。二次确认后退出软件并清除本机身份、联系人、聊天记录、密码和设置，重新启动后创建新身份；下载文件和分享的原始文件保留。
- 共享打印机支持可选密码。首次使用验证后保存专用授权，不保存明文密码；共享人修改或关闭密码后旧授权失效，启用新密码需要重新验证。
- 局域网打印机及「我的共享」卡片支持置顶，常用打印机更容易找到。

## 改进

- 手动连接保持弹窗并显示连接中状态；成功后提示并关闭，失败时说明超时、端口拒绝或网络不可达原因，保留地址以便重试。
- 自动检查更新默认开启，在启动时及每 6 小时检查，失败后 30 分钟重试；重新开启立即检查，关闭后停止自动调度。
- 语音通话独立窗口改用自定义顶栏，样式与主窗口统一。对方离线或客户端不支持通话时，点击入口显示轻提示。
- 打印卡片采用可伸缩、可换行的布局，改善长名称、状态和操作按钮在窄窗口下的显示。
- Windows 和 Linux 安装器在替换应用前检查运行状态，要求退出所有 GoIM 实例后再安装，避免旧进程继续运行。

## 修复

- 修复麒麟、统信等 Linux 桌面缺少文件选择器时无法选择或保存文件的问题。DEB 安装器自动补齐 `zenity | kdialog` 依赖，保留桌面 Portal 优先的调用顺序；无需用户敲命令。
- 系统选择器不可用时，诊断报告自动保存到默认下载目录并提示路径；新增直接复制脱敏报告，不再依赖保存对话框。
- Linux 不支持系统验证解锁时，直接禁用设置开关并说明原因；已有设置自动关闭，保留 GoIM 锁定密码，避免锁屏后才报错。

## 安装

| 平台 | 架构 | 安装包 |
| --- | --- | --- |
| Windows | amd64、arm64 | Setup 安装程序、便携版 `.zip` |
| macOS | amd64、arm64 | `.dmg`、`.zip` |
| Linux | amd64、arm64 | `.deb`、`.tar.gz` |

请用随附的 `SHA256SUMS` 校验下载。安装前从系统托盘退出所有 GoIM 实例；Linux 使用系统软件中心安装或升级 DEB，由包管理器自动安装文件选择器依赖。便携 Linux 包需要桌面已有 Portal、zenity 或 kdialog。清除用户数据不可恢复，仅影响当前数据目录，不会清除其他设备上的副本。
