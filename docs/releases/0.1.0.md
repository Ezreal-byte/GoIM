GoIM 的首个公开版本：同一局域网内可以直接聊天、传文件和分享资料，无需中心服务器。

- 支持单聊和群聊、文字、表情、图片、聊天记录与离线补发。图片可在独立窗口中放大、旋转和保存原图。
- 大文件经接收确认后传输，支持进度、取消、重试、断点续传和完整性校验。
- 文件或文件夹可生成局域网链接和二维码，可按项目设密码。电脑和手机均可通过浏览器下载；设备分享主页也可接收上传。
- 提供截图标注、应用锁、明亮／暗黑模式，以及简体中文／英语界面。

| 平台 | x86-64 | ARM64 |
| --- | --- | --- |
| Windows | `GoIM_0.1.0_windows_amd64.zip` | `GoIM_0.1.0_windows_arm64.zip` |
| Linux | `GoIM_0.1.0_linux_amd64.tar.gz` | `GoIM_0.1.0_linux_arm64.tar.gz` |
| macOS | `GoIM_0.1.0_darwin_amd64.zip`（Intel） | `GoIM_0.1.0_darwin_arm64.zip`（Apple 芯片） |

解压后运行 GoIM，请保留包内的截图工具。Windows 版未使用商业证书签名；macOS 版要求 macOS 13 或更新版本，使用临时签名，未经 Apple 公证；Linux 需要 X11 或 XWayland。网页分享通过局域网 HTTP 提供，请在可信网络中使用。

`SHA256SUMS` 包含六个压缩包的 SHA-256。六个平台通过 CI 构建和自动测试；Windows 另跑了三个独立进程的回环通信测试。真实多机和各系统的物理桌面体验仍需实机验证。
