# GoIM 0.1.20

## 新功能

- 「设置 → 常规 → 主题配色」新增松青、陶土和鸢尾，与原有经典配色一起提供四种选择。每种都有明亮和暗色两版，从左栏切换明暗时会保留所选配色。
- 在手机或电脑浏览器打开设备分享主页、共享文件夹后，可以勾选多个文件和文件夹，点击「下载所选」一次下载一个 ZIP。压缩包保留子目录和空文件夹，同名项目自动区分。设备主页中受密码保护的项目仍需分别输入密码。

## 改进

- 自定义聊天背景从会话顶部一直铺到工具栏和无边框输入框。「选择图片」按钮去掉了省略号。「背景透明度」可在 0%（原图）到 100%（仅显示主题底色）之间调节。升级时会换算已有背景设置。
- 桌面端「文件共享 → 成员共享」将全选、下载所选和刷新排在标签栏右侧。刷新按钮同时显示图标和文字，下载按钮显示已选数量。
- 语音来电浮窗显示对方头像和备注，未设置备注时显示联系人名称。红色挂断和绿色接听按钮以圆形图标呈现。应用锁定时隐藏来电身份。使用 Wayland 系统通知时，按钮外观由桌面环境决定。

## 修复

- 修复设置壁纸后，聊天输入区域仍被纯色背景遮住的问题。
- 网页批量下载期间撤回分享时，正在写入 ZIP 的大文件也会中止传输。

## 安装

| 平台 | 架构 | 安装包 |
| --- | --- | --- |
| Windows | x64、ARM64 | Setup 安装程序（.exe）、便携版 .zip |
| macOS | Intel、Apple 芯片 | .dmg、.zip |
| Linux | amd64、arm64 | .deb、.tar.gz |

网页多选下载只需将分享文件的电脑升级到 0.1.20。手机端刷新原有分享链接即可使用。
