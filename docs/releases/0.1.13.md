# GoIM 0.1.13

## 新功能

- 语音通话使用独立系统窗口，等待接听及通话期间都可以继续操作主窗口和独立会话。关闭通话窗口会结束当前通话，双方聊天记录保留通话结果与已接通时长。
- 聊天记录中的待接收文件卡片新增「接收文件」「另存为」「拒绝」操作，无需先打开文件详情。
- 联系人页面新增手动刷新，可立即重新加入局域网发现并重试已知联系人。

## 改进

- 语音通话入口移至聊天输入区工具栏最右侧，与表情、文件及截图入口保持一致。
- 聊天文件改为右侧抽屉，不再扩大系统窗口或挤压聊天内容；主窗口和双击会话打开的独立窗口均可使用。
- 界面字号同步作用于导航、联系人、聊天记录、输入框、设置及独立窗口。字号读数改为中性描边样式，并适配大字号下的导航宽度和列表行高。
- 会话、联系人及群聊卡片增加细分隔线；卡片、按钮和图标悬停区域统一使用圆角尺寸。
- 自动发现覆盖可用 IPv4 网卡，检测网卡和地址变化后重新加入发现组，保留仍有效的直连；联系人继续以密钥身份识别，不以 IP 地址新建用户。

## 修复

- 修复文件「另存为」在绘制期间重入系统对话框、重复弹出窗口及可能闪退的问题。
- 修复拖入文件时聊天记录区域出现整块蓝色遮罩的问题，提示改为输入区内的虚线框。
- 修复群成员无法彼此直连、但都能连接同一局域网节点时群文本消息无法送达的问题。新版节点可进行单跳中继，校验原发送者签名和群成员身份，保留持久化待发送队列、接收去重及最终接收者回执。
- 修复独立会话与主窗口重复打开同一通话音频设备的问题。

| --- | --- | --- |
| Windows | amd64、arm64 | Setup 安装程序、便携版 `.zip` |

| Linux | amd64、arm64 | `.deb`、`.tar.gz` |

请用随附的 `SHA256SUMS` 校验下载。群消息单跳中继需要参与的客户端及共同在线节点升级至 0.1.13；没有直连或可用中继时，消息保留待重试，不提前标记为已送达。语音音频与文件内容传输仍需要发送方、接收方之间的直连，暂不通过中继节点转发。
