# GoIM 0.1.7

本次更新扩展内网通 3.4.3055 互通，联系人会自动选择协议，无需手动关联：

- GoIM 可以建立内网通群、添加成员和改名，支持与两台原版交换三方群文字。
- 支持群内普通文件和文件夹，以及单聊和群里的 PNG、JPEG、GIF 图片。群附件双向核对实际落盘和 SHA-256，文件夹保留多层中文路径、空子目录和零字节文件。
- 支持两分钟内已发送的单聊和群聊文字撤回；接收端保留撤回状态，重复投递不会恢复原文。对方需要在线。
- 支持退出群、群主解散和移出成员，保留本机聊天历史，并按群主和成员身份校验权限。
- 支持内网通内置表情编号转换，使用 GoIM 自有表情或文字显示，不附带原版图像资源。
- 完善广播发现、上下线、离线补投、忙碌／离开状态及头像双向更新。
- 普通文件重试沿用原任务；文件夹中断后可通过新邀请从头重传，保留多层中文路径、空子目录和零字节文件。
- 群文件邀请可在 GoIM 重启后恢复；群成员移除后不再提供该会话的文件。
- 扩充隔离原版自动验收脚本与中文／英文适配进度，保留六个平台架构、十二个软件包。

**适配范围仍有限制，不代表内网通全功能覆盖。** GoIM 发给原版的单文件仍需小于 4 GiB；目录续传、完全空的根目录、群文件及群目录续传、群主转让、自定义表情包、原生共享目录和远程协助尚未完成。办公网、多网卡及不同原版版本仍需现场验证。详见[内网通适配进度](../neiwangtong-compatibility-progress.md)。
