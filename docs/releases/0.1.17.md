# GoIM 0.1.17

## 新功能

- **联系人管理**：把联系人拖到分组标题或组内成员上，即可移动分组。右键可将联系人放入默认不显示的「隐藏的联系人」，也可恢复显示。离线联系人支持删除，对方再次上线时会重新出现。
- **语音来电与通话设备**：来电时先显示带联系人头像的接听浮窗，接听后打开独立通话窗口。锁定 GoIM 或开启通知隐私时隐藏来电人的身份。通话中可右键麦克风或扬声器，临时切换设备、调整音量。
- **聊天选区与独立窗口**：主窗口和独立聊天窗口均可拖选部分文字，通过右键菜单、Ctrl+C 或 Cmd+C 复制。群成员列表现在可单独打开，支持搜索和成员管理。聊天记录、群成员等独立窗口会记住关闭时的大小和位置。原生 Wayland 会恢复尺寸，位置由桌面环境安排。
- **跨网段发现**：办公室有多个可互通的网段时，管理员可在内网 DNS 配置 GoIM 入口。各端在「设置 → 网络 → 高级网络设置 → 跨网段发现」启用后即可发现同域成员。此功能默认关闭，聊天和文件仍由设备直接传输。

## 改进

- 文件共享默认打开「成员共享」。直连的 GoIM 成员可以直接获取普通文件，在项目访问页浏览文件夹或输入共享密码。受保护项目在解锁前隐藏文件名和大小。浏览器共享页也采用目录列表，方便在子目录间浏览和下载。
- 聊天文件卡片、聊天记录、传输和共享页保留原有 17 个图标，并从 Motty 补充 32 个内置图标。Go、Python、React、PowerShell 等类型，以及 Dockerfile、README、package.json 等常见文件名，现在各有对应图标，可离线显示。
- 传输列表和聊天卡片显示发送、接收速率。接收中断后，可在传输记录的「更多传输操作」中清理该任务的临时文件，保留已接收的目标文件。
- 与原版内网通 3.4.3055 互通时，支持同步群头像，单聊普通文件已验证双向传输超过 4 GiB。单聊文件夹中断后可重新发起邀请。其他版本的内网通和内网通群聊仍要求单个普通文件小于 4 GiB。
- 中英文下载页增加实际应用预览，并提供按平台和架构选择的下载入口。
- GoIM 从本版起采用 Apache License 2.0。软件包内附许可证全文及第三方声明，可在「关于」中查看许可证名称。

## 修复

- 修复多网卡设备的成员共享链接指向错误网卡，以及重连时短暂打开旧端口的问题。发布者撤回共享后，成员目录和原链接都会失效。
- 修复飞秋／飞鸽普通文件邀请在发送端重启后无法继续取件，以及某个联系人迟迟不回执时其他会话也被阻塞的问题。补发前会重新核对源文件，内容有变更时提示重发。已与 Windows 原版飞秋 2013 验证双向中文消息和普通文件传输。
- 修复内网通重复进度回执导致速率跳动、文件夹续传把磁盘上已有内容计入下载速度，以及低速接收中断时丢失最后一段已读数据的问题。
- 修复 Linux X11 下从主窗口打开聊天记录等独立窗口时，目标窗口可能留在主窗口后面的问题。主窗口顶栏更紧凑，会话和联系人侧栏的操作按钮也能在长列表中保持可见。

## 安装

| 平台 | 架构 | 安装包 |
| --- | --- | --- |
| Windows | amd64、arm64 | Setup 安装程序（.exe）、便携版 .zip |
| macOS | Intel（amd64）、Apple 芯片（arm64） | .dmg、.zip |
| Linux | amd64、arm64 | .deb、.tar.gz |

已有 Windows Setup 或 macOS 应用用户可在「关于」中检查更新。使用 DEB 或便携版时，请从系统托盘退出 GoIM，再安装或完整解压对应架构的软件包。下载后可用随附的 `SHA256SUMS` 校验文件。

Linux 包含离线文件选择器及所需运行库。名称以 `-file-dialog-sources.tar.xz` 结尾的附件是对应依赖源码，日常安装无需下载。
