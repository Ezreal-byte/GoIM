# GoIM 0.1.10

## 截图与独立会话

- Windows 和 macOS 13.3 及以上随包提供 Shotlet 截图助手。按 `Alt+A` 或点聊天框的剪刀可框选、标注、滚动截图，确认后可粘贴到聊天。Linux 和 macOS 13.0–13.2 使用 GoIM 内置截图。
- 从会话列表拖出窗口或双击会话，可在独立窗口聊天。

## 隐私与可靠性修复

- 应用锁会隐藏独立会话、清除预览并关闭图片查看器。解锁后恢复会话窗口。
- 群消息、文件邀请和离线补发使用当前成员权限。名单更新会结清已失去权限的任务。
- 撤回分享或给项目设置密码会使原有分享领取任务失效。项目访问和设备主页上传使用各自的授权。
- 飞鸽／飞秋消息在正文和附件邀请完成持久化后才确认送达。同一电脑上的不同登录分别保留会话。升级前的旧会话历史可继续查看，旧待发项可从当前联系人重新发送。
- 接收文件和文件夹先在目标卷完成暂存，再以排他方式发布。重启后可核对已发布成品并恢复任务状态。

## 从 0.1.9 升级

Windows 的当前用户 Setup 安装版和放在可写目录中的 macOS 应用可在 GoIM 的「设置 → 关于」检查更新并安装。Windows 便携版和 Linux 可从发布页获取对应软件包。
