# GoIM 0.1.12

## 新功能

- 新增局域网打印共享。可分享本机已安装的打印机，其他成员能查看可用状态并通过独立窗口选择文件、纸张、份数、方向、页码范围、色彩及单双面后发送。
- 接收任务会自动提交到对应系统打印队列。打印双方都能查看记录，并在私聊中看到打印卡片；任务区分「已提交队列」「已完成」和「失败」。
- 单聊支持双向语音通话，包括来电接听、挂断、麦克风静音和扬声器开关。可在「设置 → 通话」选择麦克风和扬声器，并分别调节音量。

## 改进

- 文件传输与文件共享页面改为更紧凑的表格布局，增加文件搜索、大小与项目数展示，并统一操作入口。
- 设置中可调整界面字号，并同步应用到主窗口、独立聊天窗口和常用弹窗。
- 打印共享会按打印机实际报告的能力限制纸张、色彩和单双面选项，并在打印机离线或停止共享时及时拒绝新任务。

## 修复

- 打印任务在取消、断线、重试和重启恢复时会保持明确状态，避免重复提交或误报完成。
- 共享打印机不可用、任务身份冲突或接收缓存达到上限时，发起端会收到明确失败原因，不会无限停留在发送中。

## 安装

| 平台 | 架构 | 安装包 |
| --- | --- | --- |
| Windows | amd64、arm64 | Setup 安装程序、便携版 `.zip` |
| macOS | amd64、arm64 | `.dmg`、`.zip` |
| Linux | amd64、arm64 | `.deb`、`.tar.gz` |

Windows 的当前用户 Setup 安装版和放在可写目录中的 macOS 应用可通过「设置 → 关于」检查更新。便携版和 Linux 请下载对应软件包。可用随附的 `SHA256SUMS` 校验下载。打印共享需要本机已安装可用的系统打印队列；语音通话需要可用的麦克风和扬声器。
