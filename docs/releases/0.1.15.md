# GoIM 0.1.15

## 新功能

本版无。

## 改进

- 为原生协议的待握手、文件连接及 IPMSG 文件连接增加并发限制；退出时及时关闭未完成的连接，减少慢连接占用资源和拖延退出的情况。
- 中英文官网的版本展示和下载入口更新至 0.1.15，英文移动导航的无障碍标签保持英文。

## 修复

- 加强撤回消息的附件权限校验：文本消息不能携带文件控制信息，撤回时仅处理发送者自己的附件和传输，避免影响同会话中其他人的文件。
- 语音通话控制信号同时校验通话编号和对端设备身份，防止其他连接干扰正在进行的通话。
- 修复音频设备启动较慢时，刚设置的麦克风静音、扬声器静音或音量被旧设置覆盖的问题；过期设备启动任务失败也不再误结束新的通话会话。
- 修复打印接收缓存已满或接收目录不可用时，发送方一直停留在发送中并反复重试的问题，现在会明确显示拒绝或失败结果。
- 打印缓存限额计入已经接收、仍等待提交或打印完成的文件，避免慢打印队列绕过缓存限制；发送出去的打印文件不再占用本机接收额度。
- 打印失败后清理接收临时文件；本地任务状态保存失败时保留文件，避免恢复任务时找不到数据。
- 诊断报告补齐打印机名称、队列、共享人、文档名和打印任务等信息的脱敏。
- 修复英文界面在较大字号下导航和空会话侧栏文字、按钮溢出的问题，保留完整标签和无障碍名称；补齐空聊天页的英文说明。
- 修复开始下载更新后，较晚返回的发布说明无法显示、持续停留在加载状态的问题。

## 安装

| 平台 | 架构 | 安装包 |
| --- | --- | --- |
| Windows | amd64、arm64 | Setup 安装程序、便携版 `.zip` |
| macOS | amd64、arm64 | `.dmg`、`.zip` |
| Linux | amd64、arm64 | `.deb`、`.tar.gz` |

请用随附的 `SHA256SUMS` 校验下载。安装前从系统托盘退出所有 GoIM 实例。Linux DEB 由包管理器安装文件选择器依赖；便携 Linux 包需要桌面已有 Portal、zenity 或 kdialog。
