# GoIM 0.1.19

## 新功能

- 在「文件共享 → 成员共享」中，可以直接下载整个文件夹，也可以勾选多个文件和文件夹一起下载。子目录结构和空文件夹都会保留。
- 从文件共享发起下载后，GoIM 会打开「传输 → 传入」，显示下载进度和完成状态。传输表格新增「来源」列，可区分聊天、文件分享、打印共享和网页接收。
- 在设备分享主页的上传弹窗中，可以多选文件，也可以把多个文件拖入弹窗一起发送。每个文件分别显示等待确认、上传进度和接收结果。
- 网页上传默认逐个确认。接收方在 GoIM 的「传输 → 传入」中点击「接收」后，浏览器才会发送文件内容。需要连续接收时，可在「设备分享主页」菜单选择「临时免确认（10 分钟）」，也可以在设置中切换。到时或重启 GoIM 后自动恢复确认。
- 网页接收记录会保存在传输中心，包含发送方地址、文件大小和最终状态。上传过程中可以取消，已完成的文件可以从记录中打开。

## 改进

- 设置左栏可以搜索具体设置项，选中结果可直接跳转。主窗口顶栏新增作者的 GitHub 入口，可在「常规」中控制显示。
- 手动刷新局域网联系人后会提示刷新完成，并显示当前在线人数。
- 取消、拒绝、撤回传输或收到校验失败的数据时，GoIM 会自动清理对应的接收临时文件。网络中断时保留可续传的数据。
- 传输记录、文件共享和打印共享的表格支持点击表头切换升降序。传输记录超出窗口时会显示可拖动的滚动条。
- 传输和文件共享的搜索图标移到输入框右侧，搜索区更紧凑。共享打印机、最近打印和打印记录使用与传输记录相同的表格间距。
- 打开成员共享文件夹后，目录显示在「成员共享」标签下。左上角的「返回」逐级返回，右上角显示当前共享路径。
- 独立图片窗口的右键菜单新增「复制」，可将当前方向的完整图片粘贴到聊天或其他支持图片的应用。
- 网页上传弹窗加宽，点击「选择文件或将文件拖到这里」或直接拖入文件即可加入队列。
- 更换了消息提示音和语音来电铃声。待接收文件及网页接收使用与消息相同的提示音。
- 共享文件夹会跟随本地目录更新。加入、移走或重命名文件后，已打开的成员客户端和浏览器页面都会自动更新。已有文件原地保存后，列表也会显示新的版本。
- 删除或移走整个共享源后，分享者会在「我的分享」中看到「分享不可用」，其他成员的共享列表和设备分享主页会移除该项目。单个共享文件和文件夹都适用。
- 在失效项目上点击「修改共享源」，可以重新选择文件或文件夹。原分享链接和密码继续有效，接收方可以从原入口访问新内容。

## 修复

- 文件被移除后，它原来的下载链接会失效，后加入的文件会获得独立链接。同名文件批量下载时会分别保存，保留接收目录中原有的文件。
- 修复 Windows 上下载目录经过路径别名时设备分享主页可能无法开启，以及选择目录联接中的共享文件或文件夹可能失败的问题。

- 修复接收内网通文件时进度显示不准、对方重发后无法再次接收，以及图片附带的文字说明显示不全的问题。
- 更新 Viva 依赖，使用上游合入的 Linux 窗口激活、拖拽预览和 Fcitx 4 输入支持。发行包继续使用 GoIM 的 Viva fork，保留交互式来电浮窗、字号缩放和 Windows 透明文本修复。

## 安装

| 平台 | 架构 | 安装包 |
| --- | --- | --- |
| Windows | x64、ARM64 | Setup 安装程序（.exe）、便携版 .zip |
| macOS | Intel、Apple 芯片 | .dmg、.zip |
| Linux | amd64、arm64 | .deb、.tar.gz |

要让已经发出的目录链接自动更新，请将分享文件的那台电脑升级到 0.1.19。接收方升级客户端后即可使用批量下载和传入进度。
