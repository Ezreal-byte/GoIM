# GoIM 0.1.5

- 设置中的界面字体现已支持从系统已安装字体中选择，并在应用后立即更新窗口、菜单和设置页；保存的字体不可用时自动回退到系统字体。
- 个人资料“编辑资料”按钮去掉省略号；个人资料、头像裁剪、联系人资料、连接、确认、分组、快捷键、字体、密码、分享与更新等内置弹窗统一放大操作按钮，改善点击和焦点体验。
- 消息列表中的会话可以直接拖到主窗口外，在独立系统窗口中继续聊天；主窗口列表会暂时移除该会话，关闭独立窗口后自动恢复。多窗口拥有独立滚动、输入和草稿状态，并按窗口客户区几何识别前台状态，支持高 DPI。
- 收紧消息会话、联系人、本机身份和群会话卡片高度，重新调整头像及文字间距，使列表更紧凑。
- 设置 → 常规新增“开机自启”，使用 Viva 原生登录项 API 创建和移除 Windows 启动项；读取或写入失败时自动回滚并显示原因。
- 设置 → 关于新增系统诊断报告。报告包含版本、协议服务、网络适配器、存储可访问性和数据计数，并对聊天内容、联系人、地址、文件路径及凭据脱敏，便于用户反馈问题时安全排查。
- 增加中英文文案、诊断隐私、开机自启、弹窗尺寸、紧凑卡片、独立会话窗口和截图布局回归测试；CI 发布前继续执行六平台十二包验证。

Windows x64 / ARM64 提供 Setup 和 ZIP；macOS Intel / Apple 芯片提供 DMG 和 ZIP；Linux x64 / ARM64 提供 DEB 和 tar.gz。发布附带 `SHA256SUMS` 和签名在线更新清单。Windows 安装包未使用商业签名，macOS 使用 ad-hoc 签名且未经 Apple 公证。
