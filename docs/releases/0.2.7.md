# GoIM 0.2.7

## 新功能

- 私聊支持视频通话。点击工具栏视频图标即可发起视频呼叫，通话窗口支持本地画中画预览、开关摄像头与静音控制，以及右下角来电提醒浮窗。
- 远程协助支持反向发起「请求对方协助」。点击远程协助下拉菜单可选择控制对方或邀请对方协助本机；被控端浮窗可折叠为屏幕右下角贴边胶囊，随时展开或终止共享。
- 截图支持窗口保留与隐藏切换。可在设置或工具栏截图下拉菜单中选择「保留窗口截图」或「隐藏窗口截图」，工具栏点击截图完成后自动粘贴到当前聊天输入框草稿。

## 改进

- 完善混合消息输入框体验，支持跨文字与图片/文件附件的连续选中、方向键导航和撤销操作。
- 升级 Linux 内置 Shotlet 截图助手，仅在助手不可用时回退系统截图工具；通话或远程协助期间隐藏窗口截图不再异常关闭辅助窗口。
- 锁屏系统验证改用 Viva 内置系统认证能力，统一 Windows 与 Linux 解锁体验；托盘未读预览适配新版 Viva 回调接口。
- 远程桌面助手拆分为独立版本化构建与发布流程，并随正式版发布自动同步官网下载页。

## 修复

- 修复视频通话中对方无可用摄像头时，己方画面也无法正常显示给对方的问题。
- 修复 Windows 右下角桌面通知浮窗位置偏移及拖动后未记住位置的问题。
- 修复部分 Linux（如麒麟 OS）环境因 Vulkan 缺少表面扩展（`-7`）直接启动闪退的问题，现会自动回退 CPU 软渲染。
- 修复 Linux / 麒麟 OS 下从文件管理器（Peony/Qt5）拖入文件或图片到输入框卡顿或闪退、`Ctrl+V` 与右键菜单无法粘贴文件/图片，以及多窗口同进程剪贴板死锁的问题。
- 修复聊天输入框右键菜单未跟随应用界面语言（i18n）切换的问题。

## 安装

| 平台 | 架构 | 安装包 |
| --- | --- | --- |
| Windows | x64、ARM64 | Setup 安装程序（.exe）、便携版 .zip |
| macOS | Intel、Apple 芯片 | .dmg、.zip |
| Linux | amd64、arm64 | .deb、.tar.gz |

手动覆盖安装前，请先从系统托盘完全退出旧版 GoIM。可使用 `SHA256SUMS` 校验安装包。

macOS 被协助端需在系统设置中授权屏幕录制和辅助功能。Linux 的 Wayland 会话依赖桌面提供屏幕共享和远程桌面门户。
