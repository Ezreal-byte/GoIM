# GoIM 0.2.1

## 托盘未读消息

- Windows 修复折叠托盘的浮层定位。收到新消息后，把鼠标停在 GoIM 托盘图标上即可查看未读会话。
- macOS 菜单栏也支持悬停显示未读会话浮层。Linux 桌面托盘悬停时显示未读摘要，点击图标或托盘菜单的「查看未读消息」可打开交互浮层。
- 点击浮层里的会话直接进入聊天。「暂不处理」会结束本轮提醒并保留未读。锁定应用或启用隐藏通知内容时，托盘隐藏会话身份。
- 主窗口、聊天记录、媒体查看等窗口按当前窗口的实际标题栏空间布局，进入全屏时释放系统按钮占位。

## 聊天文件

- 聊天文件详情中的「打开文件」和「打开文件夹」由后台调用系统。重复操作会合并到正在执行的请求，系统打开失败时会显示提示。

## 安装包

| 平台 | 架构 | 安装包 |
| --- | --- | --- |
| Windows | x64、ARM64 | Setup 安装程序（.exe）、便携版 .zip |
| macOS | Intel、Apple 芯片 | .dmg、.zip |
| Linux | amd64、arm64 | .deb、.tar.gz |

已安装 0.2.0 DEB 的用户可在「设置 → 关于」在线更新。可以使用随附的 `SHA256SUMS` 校验安装包。
