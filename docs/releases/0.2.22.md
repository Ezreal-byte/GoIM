# GoIM 0.2.22

## 新功能

本版无。

## 改进

- 主窗口顶栏与左侧导航采用统一底色，去掉 GoIM 标识与头像之间的分隔线。聊天、联系人、传输、文件共享、打印共享和设置的内容区在右侧和底部留出窄边，并统一使用圆角。
- 经典、松青、陶土、鸢尾的明亮和暗色外观都重新调整了底色。顶栏与导航、会话与分类列表、正文各有层次，聊天气泡和当前选中项更容易区分。

## 修复

- 鼠标停在当前会话、联系人或群聊上时，列表会保留选中高亮。

## 安装

| 平台 | 架构 | 安装包 |
| --- | --- | --- |
| Windows | x64、ARM64 | Setup 安装程序（.exe）、便携版 .zip |
| macOS | Intel、Apple 芯片 | .dmg、.zip |
| Linux | amd64、arm64 | .deb、.tar.gz |

每个安装包均可使用随附的 `SHA256SUMS` 校验。Linux 的 `file-dialog-sources.tar.xz` 是文件选择器依赖源码。
