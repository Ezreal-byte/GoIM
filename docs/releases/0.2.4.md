# GoIM 0.2.4

## 新功能

- 打开聊天时自动聚焦消息输入框，进入会话后即可直接输入文字或粘贴截图。支持会话列表、联系人「发消息」、托盘未读列表、新建会话及独立聊天窗口。

## 改进

- 聊天输入框仅在主动打开会话时获取焦点；收到新消息和后台状态更新不会打断正在使用的搜索框，也不会抢占弹窗或只读会话的焦点。
- Linux 截图粘贴继续使用现有离线剪贴板组件，不增加打包依赖。

## 修复

- 修复麒麟等 Linux X11 环境中，截图复制后粘贴出现 `PNG`、`IHDR` 等乱码，无法作为图片消息发送的问题。感谢 [#13](https://github.com/Ezreal-byte/GoIM/issues/13) 的反馈与测试验证。
- 修复 Linux X11 剪贴板被其他程序接管后，仍读取旧缓存，导致偶发提示「无法读取剪贴板中的图片：clipboard holds no image」或粘贴旧文字的问题。

## 安装

| 平台 | 架构 | 安装包 |
| --- | --- | --- |
| Windows | x64、ARM64 | Setup 安装程序（.exe）、便携版 .zip |
| macOS | Intel、Apple 芯片 | .dmg、.zip |
| Linux | amd64、arm64 | .deb、.tar.gz |

已安装 GoIM 0.2.0 或更新版本的 DEB 用户可从「设置 → 关于」在线更新。手动覆盖安装前，请先从系统托盘完全退出旧版 GoIM。可使用随附的 `SHA256SUMS` 校验安装包。

本次剪贴板修复针对 Linux 直接 X11/XCB 路径；原生 Wayland、GTK、Windows 与 macOS 继续使用各自现有的剪贴板实现。
